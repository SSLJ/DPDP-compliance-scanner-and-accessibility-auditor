# DPDP-compliance-scanner-and-accessibility-auditor

AI Banking Compliance & Accessibility Auditor is a smart web platform that helps analyze banking application screens for accessibility problems and personal data privacy risks. Users can upload screenshots of banking app interfaces, and the system processes them through two analysis paths: an Accessibility Auditor and a DPDP Compliance Auditor.

The Accessibility Auditor checks whether the application is easy to use for differently-abled users by identifying issues like low text contrast, poor screen-reader support, small buttons, difficult navigation, and complex language. The DPDP Compliance Auditor focuses on detecting exposed sensitive information such as Aadhaar numbers, PAN details, account numbers, and third-party personal data, while also checking compliance with RBI masking guidelines and the DPDP Act 2023.

The project is built using React for the frontend, FastAPI for the backend, PostgreSQL for database management, and Docker for containerized deployment. AI technologies such as computer vision and NLP are used to generate automated audit reports, helping banks create more secure, accessible, and regulation-compliant digital platforms.
